# 运行时配置边界梳理任务清单

## 目标
- 明确哪些参数允许运行时修改，哪些参数只能启动时读取
- 让代码、README、示例配置和 Telegram 说明保持一致

## 任务列表
- [x] 盘点当前 Telegram 可改参数与 runtime config service 能力
- [x] 建立运行时可修改参数清单与查询接口
- [x] 明确仅启动时生效参数范围并同步文档
- [x] 补充测试并跑全量验证

## 当前分类原则
- 允许运行时修改：
  - 不涉及 API 认证
  - 不改变进程级初始化依赖
  - 不需要重建 Bitfinex / Telegram / 调度器对象
  - 仅影响后续策略执行行为
- 仅启动时读取：
  - Bitfinex API 凭证
  - Telegram token / auth token
  - 主流程调度模式与间隔
  - 借贷检查调度间隔
  - 通知格式等偏输出层初始化设定
